Mimetypes module 

It stands for Multipurpose Internet Mail Extensions 
it was originally created to allow people to send things other than plain text, so like- images, audio and attacgments thorugh email
universal standard used to declare what kind of data a file contains.

Identify the file types based on their extensions 
distinguish bw text files and binary files

dynamically reads the standard operating system files on comp to see what extensions match which file types

Follows a strict type/subtype format
text/ says: it's safe to read as characters
image/ abd application/: binary data, skip so embedding model doesnt crash
